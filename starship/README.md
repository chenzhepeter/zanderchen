# 星河战队：孤垒

十回合俯视基地防御战役。原生 Canvas 2D / ES Modules，无构建步骤或外部运行依赖。

## 运行

在仓库根目录运行 `python3 -m http.server 8080`，打开 <http://127.0.0.1:8080/starship/>，或通过根目录首页进入。页面会为入口及嵌套模块统一更新加载版本，避免刷新后混用旧界面缓存。请通过 HTTP 预览；直接打开 `file://` 可能阻止模块加载。

## 布防与军需

- 开局 **1,000 军需 + 3 颗炸弹**。推荐阵容为四面机枪与六个步兵班，花费 940，保留 60。
- **54 个部署位**：20 个沿墙步兵/喷火位、6 个内环预备位、8 个机枪位、12 个独立炮位、8 个防空平台。选装备后高亮兼容空位，方向按钮显示可用数量；已满位置不能重复付费。
- **炮塔首轮开放**，全向对地射击，使用四面各 3 个独立内侧平台；机枪不会占用炮位。墙破后内侧炮位仍可部署。
- 第 2 回合开放防空与喷火兵。喷火兵 **150 点**，覆盖近距 **10.5 / 76° 扇面**，持续喷射并灼烧 1.8 秒；仅攻击地面，重甲会抵消 35% 火焰伤害。可以像步兵一样调动和撤回内环。
- 军需实时到账：战士 4、奔袭 3、飞翼 8、重甲 35。准备、战斗和暂停时都可购买；战时新守军部署 1.5 秒后开火，战时购买不能撤销。
- 炸弹 35 点 / 颗，320 地面范围伤害、半径 5.5、间隔 1.2 秒。按 5 后点战场投掷；缺货时选卡自动购买，也能在投弹面板补充。无友军误伤，墙体与核心建筑遮挡爆炸。
- 点选守军后，战场内直接显示升级、移动操作条，也可直接拖动到高亮空位；每次购买完成会退出部署模式。整备时所有守军均可搬迁；战斗中步兵与喷火兵可调动，固定武器须等到整备阶段。维修与回收仍在整备阶段完成。装备在整备、战斗和暂停时都能升级；战时改装需 2 秒，期间停火，暂停时恢复战斗后继续改装。装备有 **I / II / III** 三级，火力倍率 **1 / 1.45 / 2.05**，生命倍率 **1 / 1.25 / 1.55**；两次升级价格分别为基础价的 80% / 120%。升级投入计入回收金额，也可在整备时撤销。

## 十回合节奏

默认 **2× 速度**，可切换 1× / 1.5× / 2× / 3×。波次出怪表均在 35 秒模拟时间以内结束；仍须消灭全部已出场和排队虫群才能清场。实际回合时长由阵容、操作与幸存虫群决定。

共 **1,864 只敌人**。后四轮提高重甲占比、空袭密度、虫体生命、攻城伤害与速度；第八轮数量略少，但重甲更多。飞翼基础速度 6.8，会蛇行、加速俯冲和横移脱离；空中生命和伤害分别采用较缓的成长曲线，保留防空装备的反制价值。

过关后幸存单位恢复 20% 生命，存活墙体恢复 80 耐久。军需、炸弹、等级与战损延续。后期要维护防线、调回撤下墙的喷火兵、升级炮塔和防空，必要时主动投弹。

## 操作与存档

`1–4` 选择基础装备，`5` 投掷炸弹，`6` 选择喷火兵；空格暂停，Esc / 右键取消指令。滚轮或 `＋ / −` 缩放，放大后拖动战场，“全景”还原。触屏使用卡片和战术面板完成部署。

存档键为 `starship.campaign.v3`。操作后与每 4 秒保存；刷新后战斗以暂停状态恢复。兼容 v1 / v2：保留军需、驻军、炸弹、战损和检查点，将旧炮塔迁往独立平台；旧三回合胜利可继续第四回合。旧存档键保留。旧版进行中的波次保留原队列，随后回合采用新节奏。失败重试恢复该回合初始整备状态，补给与击杀奖励不会重复保留。

## 验证与结构

Node.js 24+，不需要安装包：

```sh
node --test starship/tests/*.test.mjs
```

测试覆盖炮位占用、预算、装备升级、火焰扇面与灼烧、空地约束、飞翼俯冲脱离、墙体与缺口、弹道、调兵、暂停、存档迁移、重试和十回合流程。`tests/campaign-strategy.mjs` 用合法购买、维修、搬迁、升级及后期主动投弹、战时补位模拟一条参考防守路线；不向模拟注入免费资源或无敌状态。

`js/data/rounds.js` 定义回合与强度，`game.js` 调度阶段，`economy.js` 管理军需，`combat.js` 管理火力，`enemies.js` / `navigation.js` 管理虫群，`render.js` / `art.js` / `effects.js` 绘制动态画面。所有素材均本地 Canvas 绘制。启用系统“减少动态效果”时关闭镜头震动。

开发预览加 `?debug=1` 可通过 `window.__starship` 检查状态；正式页面不挂载该入口。
